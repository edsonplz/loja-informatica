# 📖 Sobre o projeto

O projeto **Loja de Informática** é uma simulação de um e-commerce especializado em produtos de tecnologia, como notebooks, monitores, CPUs e outros periféricos.

O sistema foi construído utilizando tecnologias web nativas (Vanilla JS) para proporcionar uma navegação rápida e uma interface amigável, permitindo aos usuários visualizar produtos, detalhes e gerenciar o carrinho de compras.

---

# ✨ Funcionalidades

- Catálogo de produtos de informática
- Detalhes dos produtos
- Carrinho de compras (`cart.html`)
- Interface responsiva e moderna
- Organização visual de marcas e categorias

# 🚀 Como executar

```bash
# Clonar o projeto
git clone https://github.com/edsonplz/loja-informatica.git

# Entrar na pasta do projeto
cd loja-informatica
```

**Para rodar a aplicação:**
Basta abrir o arquivo `index.html` diretamente no seu navegador, ou utilizar a extensão **Live Server** no VS Code para iniciar um servidor local.
